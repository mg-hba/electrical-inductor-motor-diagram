# Motor Winding Diagram

Version 0.1.1.1

A Kivy-based application for drawing 3-phase motor winding diagrams.

## Features

- Two Layer and Single Layer windings
- Three coil patterns: Lap, Triangle, Concentric
- Connection Mode with modular package
- Box Select, Drag & Drop, Pencil
- Zoom panel with 100x max and zoom box
- Export: SVG, PDF, PNG, JPG, EPS, DXF
- Icon-based UI (PNG with text fallback)
- App Info with docs-driven content

## Installation

    pip install -r requirements.txt
    python main0.1.1.1.py
