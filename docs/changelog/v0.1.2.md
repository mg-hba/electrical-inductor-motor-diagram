# Version 0.1.2 - Export Layout, Edit Diagram, Table Fixes

**Release Date:** 2026-11-06

## Summary

This release brings major fixes to export layout, new Edit Diagram mode
for shifting diagrams, table layout fixes, and many usability improvements.

## Export Layout (Fixed)

- `world_to_screen` in `VectorExporter` now returns mm (not px)
- `transform_x` / `transform_y` convert mm -> px (DPI 300) only once
- `scale = 1.0` (removed double scaling)
- Export now shows the **full page**, not just the bottom-left corner
- Added `EXPORT_LINE_WIDTH_SCALE` and `EXPORT_FONT_SIZE_SCALE` for
  independent control of line widths and fonts in exports

## Edit Diagram Mode (NEW)

- New menu entry: **Edit Diagram** (below Draw Style, icon `draw`)
- Two diamonds appear at `x = -1`:
  - Blue diamond = main diagram shift
  - Orange diamond = phase diagram shift
- Drag a diamond to shift the diagram vertically (rounded to grid)
- Floating panel (draggable) with **Apply / Reset / Cancel**
- Shift values stored per group in JSON:
  - `chained.main_diagram_shift_y`
  - `chained.phase_diagram_shift_y`
  - `concentric.main_diagram_shift_y`
  - `concentric.phase_diagram_shift_y`
- After Apply, existing connections (junctions, lines) are shifted
  automatically via `connection.shift_y`
- Wire points stored **without** shift; shift applied at draw time

## Table Layout (Fixed)

- Table now uses `info_area` geometry (not `GRID_y_min`)
- Two helper functions `_mm_to_world_x` / `_mm_to_world_y` convert mm to world
- Table rows split by type (`header` / `body` / `comment`)
- Separate font size, color, bold, background for each row type
- `TABLE_HEADER_FONT_SIZE_LEVEL_*`, `TABLE_BODY_FONT_SIZE_LEVEL_*`,
  `TABLE_COMMENT_FONT_SIZE_LEVEL_*` for display
- `EXPORT_TABLE_HEADER_FONT_SIZE`, `EXPORT_TABLE_BODY_FONT_SIZE`,
  `EXPORT_TABLE_COMMENT_FONT_SIZE` for export
- Header rows have distinct background color
- `_export_table_text` uses `EXPORT_TABLE_HEADER_COLOR` /
  `EXPORT_TABLE_BODY_COLOR` / `EXPORT_TABLE_COMMENT_COLOR`

## Connection Fixes

- **Diamond (**`□`**)** positions after Edit Diagram now follow shift:
  - `draw_static` applies `connection.shift_y` to wire points, junctions, lines
  - Pencil / drag subtract `shift_y` so new points are stored without shift
- `x = round(x)` removed from `_extend_or_create_vertical` and `connect_selected`
  (fixes horizontal line not aligning with diagonally-shifted wire points)
- `ref_y = round(ref_y)` removed from `connect_selected`
- Selection box (`draw_select_box`) and pencil preview now use
  `backend.world_to_screen` (fixes shifted box during selection)

## Line Widths (Fixed)

- `EXPORT_LINE_WIDTH_MAIN` (9), `EXPORT_LINE_WIDTH_PHASE_1/2/3` (2)
  only affect exports, not display
- Display uses `LINE_WIDTH_MAIN_DISPLAY`, `LINE_WIDTH_PHASE_1/2/3_DISPLAY`
- `EXPORT_LINE_WIDTH_SCALE` multiplier for exports

## Coil Span Conversion (Fixed)

- Old formula `conc = chained - (coils_per_pole - 1)` was wrong
- New formula:
  - `coils_per_pole = all_slots / (3 * poles)`
  - `concentric = chained - coils_per_pole + 1`
  - `chained = concentric + coils_per_pole - 1`
- Tested with multiple motor configurations (slots/poles/span)
- Second-arm positions now match between Chained and Concentric

## Diagram Fixes

- `y_peak` for Triangle / Concentric: `sqrt(span^2 - (span/2)^2) * 2/3`
- `x_peak` for Concentric uses first coil's offset (fixed x for all coils)
- Coil points cut at `x = 0.5` and `x = all_slots + 0.5`
- Slot label positions follow slot numbers
- All diagrams (Lap, Triangle, Concentric) render correctly
- `coil_span_adjusted = span + 1 - 0.3` used consistently for rendering
