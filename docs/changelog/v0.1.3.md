# Version 0.1.3 - Package Refactor & Edit Diagram

**Release Date:** 2026-11-06

## Summary

This release focuses on code structure (splitting large files into
packages) and adds Edit Diagram mode. Also fixes connection shift
behavior after Edit Diagram, table layout, and export layout.

## Architecture Refactor

### core/base_diagram.py -> core/base_diagram/ (package)

The old ~900-line file is now split into:

- base_diagram.py       (coordinator)
- diagram_cutting.py    (wrap + cut operations)
- diagram_edit_mode.py  (Edit Diagram mode + diamonds)
- diagram_labels.py     (slot numbers, phase labels, motor name)
- diagram_table.py      (table geometry, labels, draw, export text)
- diagram_connection.py (restore connections, connection mode)

### dialogs/project_setup.py -> dialogs/project_setup/ (package)

Split into:

- project_setup.py           (coordinator)
- setup_project_info.py
- setup_motor_settings.py
- setup_diagram_settings.py
- setup_physical.py
- setup_coil_specs.py
- setup_paper.py
- setup_actions.py
- setup_wire_turns.py
- setup_span_controls.py
- setup_focus_chain.py
- setup_project_data.py
- setup_sections.py
- setup_validation.py

### main0.1.3.py -> app/ (package)

The ~1400-line main file is now split into:

- app/main_app.py                  (coordinator)
- app/app_orientation.py           (orientation + resize)
- app/app_zoom.py                  (zoom panel + actions)
- app/app_diagram_widget.py        (create/recreate diagram)
- app/app_main_ui.py               (header, info, buttons, widget)
- app/app_actions.py               (draw, reset, rotate, export, motor info)
- app/app_menu.py                  (main menu + open dialogs)
- app/app_app_info.py              (app info, docs, changelog)
- app/app_info_labels.py           (info labels at top)
- app/app_edit_diagram.py          (Edit Diagram mode)
- app/app_connection.py            (connection panel open/close)
- app/app_connection_actions.py    (connection handlers)

## Edit Diagram Mode (NEW)

- New menu entry: **Edit Diagram** (below Draw Style)
- Two diamonds at x = -1:
  - Blue diamond    = main diagram shift
  - Orange diamond  = phase diagram shift
- Drag a diamond to shift the diagram vertically
- Shift is rounded to grid
- Floating panel with Apply / Reset / Cancel
- Shift stored per group in JSON:
  - chained.main_diagram_shift_y
  - chained.phase_diagram_shift_y
  - concentric.main_diagram_shift_y
  - concentric.phase_diagram_shift_y

## Connection Shift Behavior (Fixed)

- Wire points are stored WITHOUT shift in JSON
- Shift is applied at draw time (connection.shift_y)
- Existing connections shift automatically after Edit Diagram
- Pencil / drag subtract shift_y from touch world coords
- New lines are stored without shift

## Export Layout (Fixed)

- world_to_screen returns mm (not px)
- transform_x / transform_y convert mm to px (DPI 300) only once
- scale = 1.0 (removed double scaling)
- Export shows the full page
- EXPORT_LINE_WIDTH_SCALE and EXPORT_FONT_SIZE_SCALE multipliers

## Table Layout (Fixed)

- Table inside info_area (not GRID_y_min)
- _mm_to_world_x / _mm_to_world_y convert mm to world
- Row types: header / body / comment
- Separate font size, color, bold, background for each row type
- Display and export controlled separately

## Coil Span Conversion (Fixed)

- coils_per_pole = all_slots / (3 * poles)
- concentric = chained - coils_per_pole + 1
- chained = concentric + coils_per_pole - 1
- Second-arm positions match between Chained and Concentric

## Diagram Fixes

- y_peak for Triangle / Concentric: sqrt(span^2 - (span/2)^2) * 2/3
- x_peak for Concentric uses first coil offset
- Coil points cut at x = 0.5 and x = all_slots + 0.5
- Slot labels follow slot numbers

## Line Widths

- EXPORT_LINE_WIDTH_MAIN (9), EXPORT_LINE_WIDTH_PHASE_1/2/3 (2)
  only affect exports, not display
- Display uses LINE_WIDTH_MAIN_DISPLAY, LINE_WIDTH_PHASE_1/2/3_DISPLAY
