# Version 0.0.9.2 — Group Separation & Config Cleanup

**Release Date:** 2026-10-06

## Config Cleanup

- Removed ALL motor-related data from `config.json`
- `config.json` now contains only application settings:
  - spinner_settings
  - window_settings
  - app_settings
  - grid_settings
  - connection_settings
- Automatic migration from old config format

## Chained / Concentric Separation

- Each project JSON has two isolated groups:
  - "chained": Lap and Triangle patterns
  - "concentric": Concentric pattern
- `active_pattern` in root determines which group is used
- Switching patterns never destroys other group data
- Connection data stored in dedicated keys:
  - `chained_connection`
  - `concentric_connection`

## Pull Bug Fix

- Fixed double processing when both a wire point and its attached
  line were selected
- Uses `processed_positions` set to skip duplicates
- Result: `|` moves exactly N grids as specified

## Hollow Junction Squares

- Junctions now drawn as hollow squares
- Wire points also drawn as hollow squares
- Only phase markers (R/U) remain filled

## Open Project Behavior

- Old project connection data is fully cleared
- New project data replaces session config
- Auto-draw runs after Open without user action
- Connection lines appear automatically
