# Version 0.1.0 — Major Architecture Rewrite

**Release Date:** 2026-10-09

## Summary

Full rewrite of the connection system into a modular package, plus new input
modes (Box Select, Drag & Drop, Pencil), performance improvements, and a
dropdown main menu.

## Connection System (Full Rewrite)

- Modular connection package:
  - models / geometry / topology / operations
  - selection / renderer / layer
- 3-button conflict dialog: Connect / Pass Over / Stop Before
- Golden rule: no point on a line without a junction
- Select attached line when clicking an endpoint
- Auto-deselect after operations
- Enter in pull input box = `|` action

## New Input Modes

- Box Select (contain left→right, intersect right→left)
- Drag & Drop for junctions (grid snap)
- Pencil mode to draw new H/V lines
- Hand / Select toggle in toolbar

## Performance

- Layer stack (6 layers) with selective rebuilds
- Cached world-to-screen transform
- Faster touch response in Connection Mode

## Main Menu

- Dropdown menu groups all actions
- File: New/Open, Export, Import
- Style: Draw Style, Add Pattern (Coming Soon)
- Connection Mode toggle
- Tools: Settings, Log Manager
- Info: Motor Info, App Info, Exit

## UI

- Version suffix on every window title
- zarin.png logo in top-left and top-right of exports
- Logo shown next to Draw button in main screen
- Project Setup dialog reorganized
- New focus order (winding before spans)

## Technical

- `constants.py` split into `utils/constants/`
- `debug_logger` rebuilt on Python logging
- `VectorBackend.load_paper_from_config` added
- `ensure_group_structure` fully guarded
