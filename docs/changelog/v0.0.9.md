# Version 0.0.9 — Connection Mode & Coil Patterns

**Release Date:** 2026-10-01

## Coil Patterns

- Lap (distributed winding, rectangle shape)
- Triangle (chained triangle, uniform peak)
- Concentric (concentric triangles, varying peak)
- Pattern groups: Chained (Lap, Triangle) and Concentric
- Radio button selection with pattern icons

## Two Coil Spans

- `coil_span_chained` and `coil_span_concentric` stored separately
- Automatic recomputation when one is edited
- Radio buttons in New Diagram and Draw Style

## Connection Mode

- Toolbar under main buttons
- `|` button: pull selected wires down by 1 unit
- `_` button: connect selected wires with horizontal line
- `X` button: delete mode
- `R` button: mark wire as phase start
- `U` button: mark wire as phase end
- Selected wires shown as P1_s, P1_e, P2_s, P2_e
- Connections and phase endpoints saved to JSON

## New Diagram Dialog

- Renamed from Project Setup to New Diagram
- Focus on Name input at startup
- Two span inputs with Chained/Concentric radio
- Slot Length, Core Diameter, and Unit fields
- Comments dialog with multiline input

## Table Updates

- 7 rows x 6 columns
- New UNIT column
- New SLOT LENGTH column
- New CORE DIAMETER column
- COMMENT row spanning all 6 columns
