# Version 0.0.9.1 — Connection Improvements

**Release Date:** 2026-10-03

## Connection Panel

- Added numeric input box between `|` and `_` buttons
- Pull step: enter 1 to 5, applied to line length
- Delete Mode + `|` shrinks the selected line from bottom
- Shrinking respects minimum length
- Shrinking cannot go past horizontal lines

## Junction Rules

- Invalid junctions auto-removed after every action
- Invalid = 2 collinear lines without perpendicular branch
- When invalid junction removed, lines merge together
- Valid junctions: endpoint, T-junction, Cross

## Pull Behavior

- On vertical line: extends down by step (1-5)
- On horizontal line: adds vertical line from LEFT endpoint
- On junction: extends downward or creates new vertical
- If junction at bottom exists, it moves with line end
- New lines are added to selection (green)

## Path Blocking

- Cannot draw on existing lines (same direction overlap)
- Error message: "Cannot draw on existing lines"
- Silent ignore when blocked by junctions on path

## Save and Restore

- Apply saves connections directly to project JSON file
- When opening a project, diagram draws automatically
- All connections loaded from project_data on Draw

## Zoom and Pan

- Always active, even in Connection Mode
- Double-tap to clear all selections
- Selection preserved during pan and zoom

## Phase Labels

- R/U labels shown next to marked endpoints
- Font size increased to 32sp
- 1-grid offset from the node

## Layout

- Table cells height = 1.5 grid units
- Table bottom sits at grid bottom
- 3-grid gap between table and diagram
