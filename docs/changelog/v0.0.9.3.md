# Version 0.0.9.3 — Smart Landing & Performance

**Release Date:** 2026-10-07

## Connection Mode

- Smart landing dialog with 3 options:
  1. Stop Before: end 1 grid above the line
  2. Connect: create junction + split the line
  3. Pass Through: extend 1 grid below the line
- Point-to-line selection extension
- Clicking the endpoint of a single line also selects that line
- Works for both `|` and `_` operations
- Auto-deselect after successful `|` or `_`
- Input Box + Enter triggers `|` operation
- Performance optimization in `on_touch_move`
- Hollow junction and wire point squares

## Project Setup

- Slot Length / Core Diameter / Unit moved to row 2
- Focus order updated: Name → Power → Conn → Winding → Spans →
  Slot/Core/Unit → Wire → Turns → Paper → Orientation → Comments →
  OPEN → SAVE → CANCEL
- Reduced vertical spacing between labels
- Compact layout for smaller screens
