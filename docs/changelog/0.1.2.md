# Version 0.1.1.2 — Wrap Coils at Boundary & Preserve Arms

**Release Date:** 2026-10-17

## Summary

Two related fixes for winding diagrams:

1. Chained ↔ Concentric conversion now preserves both arms
   (first and second) in the same slots.
2. Coils that cross all_slots are wrapped back onto the
   beginning of the diagram, and the grid no longer includes
   extra space beyond all_slots.

## Change 1 — Preserve Arms in Pattern Conversion

### Problem

When converting a chained winding to concentric, the first arms of
each coil were kept in place, but the second arms were mirrored and
shifted. For example (60 slots, 4 poles, chained span = 13):

- Chained: first arms 1,2,3,4,5 — second arms 15,16,17,18,19
- Concentric (old): first arms 1,2,3,4,5 — second arms 22,21,20,19,18

The old formula `conc = chained - (coils_in_pole - 1)` was half the
correct value.

### Fix

- ConcentricPattern.get_coil_span_x now treats coil_span as the
  smallest coil's span (innermost, coil_index = N-1) and computes
  each coil's span as:

  span(coil_index) = coil_span + 2 * (N - 1 - coil_index)

- The conversion formula in draw_style_dialog.py and
  project_setup.py is now:

  conc = chained - 2 * (N - 1)
  chained = conc + 2 * (N - 1)

### Result (60 slots, 4 poles, chained span = 13)

- Chained: first arms 1,2,3,4,5 — second arms 15,16,17,18,19
- Concentric (new): first arms 1,2,3,4,5 — second arms 15,16,17,18,19

Both arms are preserved in both patterns.

## Change 2 — Wrap Coils at Boundary

### Problem

For 60 slots and chained span = 13, coils extended beyond slot 60
(up to about slot 75). The grid was all_slots + coil_span + 2,
so the diagram stretched far beyond the actual 60 slots.

### Fix

- New method _wrap_coil_segments(coil_start, coil_end) in
  BaseMotorDiagram splits a coil into up to two segments:
  - If coil_end <= all_slots + 0.5: one segment [coil_start, coil_end]
  - Otherwise:
    - [coil_start, all_slots + 0.5]
    - [0.5, coil_end - all_slots]

- draw_coil in two_layer.py and single_layer.py now calls
  _wrap_coil_segments and draws each segment.

- _rebuild_grid_bounds now uses:

  x_range = all_slots + 2

  instead of all_slots + coil_span + 2 + ...

### Visible result

The diagram is drawn from +0.5 to all_slots + 0.5. The wrapped
copy appears in the first slots, on the same layer, with no extra
overlay layer.
