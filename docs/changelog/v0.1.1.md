# Version 0.1.1 — Button Icons & Full Refactor

**Release Date:** 2026-10-10

## Summary

Major update: full icon support for all buttons, files split into smaller
modules for maintainability, several bug fixes in Connection Mode, and a
complete rewrite of the App Info window.

## New Features

### Icon System
- All 115 buttons now support PNG icons
- Icon files organized in subfolders: main / menu / zoom / connection /
  conflict / app_info / docs / setup / file_ops / common / misc
- Automatic fallback to text if an icon file is missing
- Central `IconButton` component in `ui/icon_button.py`

### Zoom Panel (Rewritten)
- All zoom buttons in a single horizontal line
- `Z_Box` is now a toggle: while active, draw rectangle repeatedly to zoom
- Zoom history: 4 levels of undo, 4 levels of redo
- Zoom out cannot exceed the auto-fit boundary
- Zoom in max: 100x (was 10x)
- Anchored zoom: zooms toward the current operation point
- Panel collapses to a single `Z` button, expands on click

### App Info Window (Rewritten)
- Lightweight structure: 6 category buttons + header
- Header always shows: Zarin logo, factory name, developer names
- Categories: Version History, TODO, Structure, Features, Architecture, Credits
- Content stored in `docs/*.md` files, not hard-coded
- Changelog viewer with tree view of all versions
- Docs viewer with View Raw toggle
- Content opens on top of App Info (stacked popups)

### Main Menu (Rewritten)
- Dropdown appears directly under the Menu button
- No animation, Windows File-menu style
- No title bar
- Auto-dismiss on outside click

### Connection Mode Fixes
- Pull dialog appears **one step before** the point reaches the line
- Single dialog for multiple selected lines
- Selecting an endpoint selects its attached line
- Junction with 2+ lines cannot be deleted alone
- 2 horizontal lines + `_` button: closest two junctions found,
  vertical lines auto-selected, horizontal lines auto-deselected
- Pencil: new line must attach to existing point/line at one end

### Project Setup
- Focus does not go to Paper / Orientation spinners
- Fixed focus order after Connection spinner
- Reduced label spacing for compact layout

### Font Fixes
- Draw / Reset / Rotate buttons: larger, more readable font

## Architecture Refactor

### Files Split

- `core/connection/operations.py` → `operations.py` + `pencil_ops.py`
  + `conflict_ops.py` + `topology_ops.py`
- `core/connection/layer.py` → `layer.py` + `layer_history.py`
  + `layer_json.py`
- `diagrams/base/diagram_base.py` → `diagram_base.py` + `zoom_controller.py`
  + `touch_handler.py` + `layer_renderer.py`
- `dialogs/project_setup.py` → `project_setup.py` + `setup_sections.py`
  + `setup_validation.py`
- `dialogs/open_save.py` → `open_save.py` + `file_browser.py`
- `ui/connection_panel.py` → `connection_panel.py` + `connection_buttons.py`
- `dialogs/app_info.py` → `app_info.py` (rewritten, lightweight)
  + `docs_viewer.py` + `changelog_viewer.py`

### New Modules

- `managers/docs_manager.py` — reads docs/index.json and markdown files
- `ui/icon_button.py` — IconButton component with fallback
- `ui/connection_buttons.py` — button factory for connection panel
- `diagrams/base/zoom_controller.py` — zoom & pan logic
- `diagrams/base/touch_handler.py` — touch dispatch
- `diagrams/base/layer_renderer.py` — layer drawing
